# 第一次选项目：先试走一个，再扩大清单

先问一个能排除选项的问题：**即使录取，什么条件会让你不去？** 例如总支出超过可承担上限、开学前不能完成本科学业，或课程几乎不涉及目标岗位需要的方向。不要给单凭校名、排名或往年分数生成的“保底”承诺。

## 用一条项目记录跑通

1. 用申请人的目标方向、入学季、全日制或兼读、预算币种筛项目。资料不全时先做一个样例，标出还差哪条事实；不用为了建表索取护照、学号或完整成绩单。
2. 打开该校当期项目页，确认项目、学院、校区、学位类型和入学批次。再比对研究生院通则与项目专属要求；若网页只写学校最低要求，不据此断言专业没有额外要求。将链接、核对日和适用对象与结论放在一起。找不到当季说明则记“未公布，待核”；历年时间可用于安排复查，不能填进本年官方截止栏。
3. 为每个项目区分硬门槛、申请人偏好、未知项。对照学士背景、先修课、语言成绩类别及有效期、授课形式、是否要求推荐或额外文书；标明“不符合／符合已知门槛／证据不足”，不把“符合最低要求”写成录取预测。材料或证明还没开出与申请资格不足是两件事。
4. 比较总负担：申请费、整个学制的学费（留意按学分还是按年）、生活费及必要一次性支出。金额写币种、时期、来源；个人估算单列。如果留位费最终抵学费，可列为前期现金需求，不重复计入总成本。缺学费、学制或奖学金结果时用区间或未知，不当作零。
5. 排序时保留两个理由：为什么值得申请，以及眼下最可能卡住什么。分别列开放日、轮次截止、推荐截止、内部目标和校方时区；没有精确时刻不默认为午夜。优先安排依赖外部出件或老师答复的事项。校方公布变更才更新官方日期，保留上一条的核对日期。

对一般国内本科，先确认本校何时能出完整成绩单、评分说明和预计毕业证明。对中外合办，先查明是一校学籍、双学籍、双学位还是交换；这几个词不能互换。把两校可能不同的出件时间和材料要求计入计划。真正录入字段时再逐校映射，不以“合作办学”决定一律填一行或两行。

## 最小交付和停止点

输出“项目｜为何考虑｜硬门槛及证据｜预算或缺口｜下一个期限及其性质｜负责人和下一步”。给一个今天就能做完的动作。假设甲项目目前只有去年网页，而乙项目本年要求齐全：今天可先对照乙的先修课并向教务查出件周期；甲只设置一次查证节点，无需先写两份定制 PS。

若目标已明确且问题是“这个专业英文填哪一行”，转材料与网申核对；若已录取、要选接受日期，转录取信核对。计划不授权开账号、索取第三方私人资料、付款或提交。
