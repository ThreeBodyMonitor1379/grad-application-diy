# 提交前，把每个值还给出具它的学校

先问清申请表在数什么：就读院校（institution attended）、学位资格（qualification）还是颁授院校（awarding institution）。一人两校、一个合作项目、两张成绩单，不自动等于两个已获学位。先辨认申请季、项目和表单字段，再决定写几条。

1. **分两次判断。** 注册事实决定做几张学校卡，授位证据决定填几项资格。普通一校一学位走 A；确有两校学籍走 B，包括只拟获一个联署学位的学生（两张学校卡、一项拟授资格）。仅交流、联合教学或注册状态不清，先核实是否属就读史；授位证据不全只挂起资格字段，不推翻已核实学籍。读[双学籍填表指南](双学籍填表指南.md)，按对应路线工作。
2. **做字段表。** 输出「院校｜字段原文｜拟填值｜这所学校的证据及页码｜已证实／待问」。先核对英文专业与学位名称，再核成绩满分和学期、学习地点、注册起止、完成与授位日期。必填但证据不支持的值是阻塞，不是让申请人随便选。
3. **给出上传清单。** 每项写目标项目、栏位、颁发机构、语言、覆盖学期、评分说明、格式限制和传送人。能用低敏感文件证明就不另交带证件号的原件；认证、官方直送和个人上传不可互换。保护原件，在副本做排版；数字签章文件按要求保留，必要时请出具机构另发。
4. **提交前检验。** 对照门户预览逐条检查，特别看相邻教育记录是否被自动带入上一条的值。副本打开后看首页、末页、章、页序；软件提示不接受文件时先保存提示与版本。保存并重开草稿，只有能实际读回的值才记为已保存。不能下载时写“看到文件名”，不能写“已验收”。
5. **交付。** 列明可填、留空、需校方确认、由本人决定的栏位。遇到问题给出一个具体问题和应附的最小证明。最后告诉申请人哪一个未解决事项会阻止下一步。仅核对时不上传；上传需在接收方和文件范围获得授权，不代作声明、支付或最终提交。

例：两所学校的英文材料使用相近但不同的专业名，其中一校只给单科分数。各自照录专业名；不将另一校均分复制过来。若已经提交，保存两行更正对照，按项目官方渠道处理；后续跟进单独记回执。
