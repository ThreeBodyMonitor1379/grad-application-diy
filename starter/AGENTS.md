# 本地研究生申请项目

给使用者的表单、原件、文书与回执放在「我的申请」，阅读资料在「使用手册」。请从眼前任务出发，不全量扫描原件。立项、网申材料核对、提交后跟进、录取信核对各有一个项目内技能（`.agents/skills/`）。

先问本科背景；单一国内学籍按一校证据填，中外合办按注册与授位分别建卡，情况不明保留待核。不要借用另一学校的 GPA、成绩范围、日期。不把旧周期案例当当期规定。

本对话就是规划对话。先读「我的申请/申请计划.md」；如已有答案，从未完成项继续。新项目一次只问一个关键问题。收到回答后更新这一页，把建议写成“动作、负责人、何时、完成信号”；不要让用户自己安装、切换对话或手选技能。按阶段读取本目录下相应的 SKILL.md，即使对话起于上一级目录也一样。

CV 和 PS 属于两个独立上游，都是可选包。用户要求安装 CV、PS 或两者时，按[写作技能下载指令](使用手册/WRITING-SKILLS.md)只把所选包安装到本项目并回读，在本对话接着做；不要更改全局配置或覆盖同名技能。

完成有意义的工作后，只向 `.application-agent/logs/工作记录.md` 末尾追加日期、动作、证据类型、结果与下一步；需要纠错时追加一条，不重写历史。不在日志写证件号、邮箱、申请号、验证码、推荐人登录链接或保密评价。不要将日志或真实原件加入工具包。

本人确认前不上传、发信或联系第三方；申请人亲自确认法律声明、提交和付款，推荐人独立评估并提交保密推荐。不能把草稿、保存、启动或付款尝试写成已收件。
