# 从这里开始

今天先选一个你想读的项目。打开[项目要求](我的申请/项目要求.md)，记下官网、入学季和你还不确定的一件事。暂时没有目标学校也没关系：打开本目录里的 **启动对话.command**，从本科背景聊起。

| 想做什么 | 去哪里 |
|---|---|
| 看一个从选校走到录取的例子 | [新手手册](使用手册/从这里开始.md) |
| 核对合办项目的两校学籍、授位和成绩 | [双学籍指南](使用手册/双学籍填表指南.md)；普通国内本科直接按本校证明填 |
| 整理已核实的事实 | [事实与证据](我的申请/事实与证据.md) |
| 核对网申、跟进补件与回执 | [提交前核对](我的申请/提交前核对.md) · [提交后待办](我的申请/提交后待办.md) |

资料只放「我的申请」：学校签发的文件放「材料原件」，修改中的版本放「文书草稿」，学校发来的确认放「提交与回执」。一个项目用一份表，增加项目时复制空表并改名。不要把这个个人文件夹推到公开仓库或放进公共共享盘。

在 Mac 双击「启动对话.command」；Linux / WSL 可在本目录的终端运行 `sh ./启动对话.command`。有 Codex CLI 时会在终端发出开场问题；只有 Mac 桌面端时，看到预填文字后按发送。未安装或不想使用 AI，照手册也能完成。需要 CLI 时见 [Codex 官方入门](https://developers.openai.com/codex/cli/)；不必把账号、密码或验证码写入项目。再次运行启动器会开一个新对话；要继续原对话，请从 Codex 历史记录选择。

「AGENTS.md」给助手读。安装标记、日志和技能分别放在隐藏目录「.application-agent」和「.agents」，平时不用打开。隐藏并非加密；请妥善保存本机资料。
